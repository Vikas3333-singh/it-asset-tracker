The Problem

Asset data scattered across Excel silos

At Femmella Fashions, asset data lived in multiple Excel files owned by different people. Cross-referencing them manually to answer "who has this device?" or "what's in stock?" cost the support team hours each week — and led to duplicate L1 tickets that ServiceNow access would've instantly resolved.

The Solution

One dashboard. Your existing files. No migration.

Built a browser-based tool that ingests any Excel file format the team already had — tolerating typos, inconsistent column names, messy real-world exports. Smart header detection, status normalization, and live filter-aware KPIs meant zero adoption barrier. Drop file, get answers.

What It Does

Smart Excel Ingestion

Drag-drop any .xlsx or .xls file. Multi-file merge, smart header detection, auto column mapping — handles messy real-world exports without cleanup.

Live Filter-Aware KPIs

6 KPI cards that update in real time as filters change — Total Assets, Assigned %, Repairing %, In Stock %, Unique Users, and Departments.

4 Interactive Charts

Equipment type breakdown, department distribution, top asset holders, and status distribution — all built with Chart.js 4.4 and responsive to active filters.

Full-Text Search + Filters

Simultaneous search across name, department, type, description, and serial. Combinable dropdown + quick filters. One-click reset.

Export to Excel

Download any filtered view as .xlsx with one click. What you see is what you export — perfect for sharing snapshots without giving full access.

Entirely Offline

No server, no API calls, no data leaves the machine. Works offline in any modern browser — no installation, no npm, no build step required.

Tech Stack

HTML5 CSS3 Vanilla JS Chart.js 4.4 SheetJS (xlsx 0.18) IBM Plex Mono CDN-only · No npm
