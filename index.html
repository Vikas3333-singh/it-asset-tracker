Problem, solution and result

Why it was built and what changed after it went live.

Problem

Asset data was split across Excel files owned by different people

Answering “who has this laptop?” or “what is in stock?” meant cross-checking several sheets by hand. It cost the support team hours every week and created duplicate L1 tickets that ServiceNow access would have resolved instantly.

Solution

One dashboard on top of the files people already had

The tool reads messy real-world exports, including typos and inconsistent column names. Header detection and status clean-up are automatic, so there was nothing to learn and nothing to migrate.

Result

~35%

fewer L1 tickets in the first month

Support staff could look up asset owners and stock themselves, without needing ServiceNow access.

Design choices and current limits

What the no-backend approach buys, and what it costs today.

Why it works this way

  • One HTML file. Nothing to install or approve, so the team could start the same day.
  • Runs in the browser. No server and no API calls, so asset data never leaves the machine.
  • Reads your existing Excel files. No migration, and nobody has to change how they keep records.

What it does not do yet

  • No saved data. Files must be loaded again each session.
  • No shared or live data. Each person works on their own loaded copy.
  • No warranty alerts, maintenance history or barcode lookup. These are the next planned additions.
