IT Asset Tracker dashboard

A browser-based asset dashboard built for real operational use at Femmella Fashions. Upload the Excel files you already have and see the whole device inventory.

Problem

Asset data was split across Excel files owned by different people

Answering “who has this laptop?” or “what is in stock?” meant cross-checking several sheets by hand. It cost the support team hours every week and created duplicate L1 tickets that ServiceNow access would have resolved instantly.

Solution

One dashboard on top of the files people already had

The tool reads messy real-world exports, including typos and inconsistent column names. Header detection and status clean-up are automatic, so there was nothing to learn and nothing to migrate.

Result

~35%

fewer L1 tickets in the first month

Support staff could look up asset owners and stock themselves, without needing ServiceNow access.

What it does

Six features that cover the daily questions a support team asks about assets.

Excel ingestion
Multi-file merge, smart header detection and automatic column mapping for messy exports.
Live KPIs
Total assets, assigned, repairing and in-stock percentages, unique users and departments update as you filter.
Four charts
Equipment type, department, top asset holders and status, all responsive to active filters.
Search and filters
One search box across name, department, type, description and serial, combined with dropdown filters.
Excel export
Download the filtered view as .xlsx to share a snapshot without sharing full access.
Fully offline
No server and no API calls. Data never leaves the machine, and nothing needs installing.
