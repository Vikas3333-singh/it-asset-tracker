# IT Asset Tracker

A web-based IT asset tracking application built to help IT teams maintain clear visibility of devices, ownership, warranty status, and lifecycle stage in one place.

## Overview

In many organizations, asset information is often scattered across spreadsheets, emails, and manual records. This project centralizes key asset details into a simple dashboard interface, making it easier to manage devices, monitor ownership, and track operational status efficiently.

## Key Features

- Add and view IT assets from a centralized dashboard
- Track assigned users, departments, and locations
- Store asset ID, serial number, and device details
- Monitor warranty expiry information
- Manage lifecycle stages such as In Use, In Stock, Repair, and Retired
- Search and filter records for faster tracking
- Improve inventory visibility through a simple dashboard layout

## Business Use Case

This project is useful for:

- IT support teams managing end-user devices
- Asset management teams maintaining inventory records
- Endpoint support engineers tracking ownership and warranty
- Small and mid-sized organizations handling assets manually
